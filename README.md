# Hyllo Skills

## Install

### npx skills

```bash
npx skills add HylloAI/skills
```

### Manually

#### Claude Code

Add the contents of this repo to a `.claude/skills` folder you're using with Claude Code. See more in the [official Claude Skills documentation](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview).

#### Codex CLI

Copy all directories in root into your Codex skills path (typically `~/.codex/skills`). See the [Agent Skills specification](https://agentskills.io/specification) for the standard skill format.
